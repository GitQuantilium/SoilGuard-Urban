Hubungkan Sensor

BLUETOOTH LE (HP & Laptop) — UTAMA
Butuh alat dengan BLE (mis. ESP32 + sensor). Nama perangkat berawalan "SoilGuard". Layanan UART: 6E400001-... (Nordic UART). Pasti jalan di Chrome/Edge (Android & desktop). Di iPhone, Web Bluetooth masih eksperimental — bila tidak tersedia, gunakan mode "Jembatan WiFi/Cloud" di bawah.
JEMBATAN WIFI/CLOUD (SEMUA PERANGKAT — TERMASUK iPHONE)
Cara kerja: alat (ESP32 + WiFi) mengirim pembacaan ke tabel sensor_bridge di Supabase; aplikasi menarik otomatis tiap 3 detik. Siapkan SQL langkah 2c (PANDUAN-SUPABASE.md) & firmware (ALAT-BLUETOOTH.md).
USB SERIAL (Laptop - Electron/Browser)
WEB SERIAL API (Browser - Chrome/Edge)
Bekerja langsung di browser (tanpa Electron). Hanya Chrome/Edge.

🧮 Kalkulator Media & Dosis

Perkiraan dosis umum (media pot/polybag & bedengan setinggi ±20 cm). Selalu ikuti label kemasan pupuk & kondisi tanamanmu.

Nilai yang ditambahkan ke pembacaan sensor. Contoh: alat menunjukkan pH 6.1 padahal standar 6.5 → isi +0.4 di kolom pH.
